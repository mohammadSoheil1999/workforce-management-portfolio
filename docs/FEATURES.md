# Features

## Workforce and attendance

Employee lifecycle, dated rates, automatic/manual work entries, breaks, overnight shifts, templates, batch start/finish, location data, and imports.

## Payroll and finance

Hourly and daily calculations, contractor behavior, travel allowances, advances, partial settlement, carried balance, month locking, reversals, income/expense categorization, and linked payment expenses.

## Reporting and governance

Payroll PDFs, spreadsheet-compatible export, dashboards, audit events, role-based access, employee self-service, and light/dark RTL presentation.
